# Dinnah Arthur Ugochukwu — Portfolio

Next.js (App Router) portfolio site.

```bash
npm install
npm run dev
```

## Add your files

- **Images** → `public/images/` — file names are listed in `lib/assets.ts` (rename your files or edit the paths there).
- **Fonts** → `public/fonts/` — names are declared at the top of `app/globals.css`:
  `Axiforma-Regular/Medium/Bold.otf`, `AvantGardeLT-Book/Demi.otf`, `Rillosta.otf`, `CalifornianFB-Reg.otf`.

## Edit content

Everything written on the site (work items, jobs, skills, contact details) lives in `lib/content.ts`.

## Tool badges

`components/ToolBadges.tsx` draws the Ps / Ai / CDR badges as SVG. Swap in the official logo files if you prefer.
